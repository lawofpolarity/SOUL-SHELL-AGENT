## Non-inference rules

1. A variable named `Identity` is not evidence of personal identity.
2. A variable named `memory` is not evidence of persistent memory.
3. A numerical norm called `RSCS` is not the canonical RSCS metric.
4. Executable code does not validate the conceptual interpretation.
5. Passing unit tests demonstrates only the tested software properties.
6. Mathematical notation does not by itself establish empirical truth.
